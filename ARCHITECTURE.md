# Архитектура «Адал Кеңесші»

```
 Пользователь
   │  текст / голос (каз., рус.)
   ▼
┌─────────────────┐   ┌──────────────────┐
│ Telegram-бот    │   │ Веб-интерфейс    │   ← Frontend (aiogram 3 / HTML+JS)
│ telegram_bot.py │   │ web/index.html   │
└────────┬────────┘   └────────┬─────────┘
         │                     │ REST API (FastAPI, web_app.py)
         └──────────┬──────────┘
                    ▼
        ┌────────────────────────┐  голос → Whisper (Groq) → текст
        │  Assistant.ask()       │  app/assistant.py — Backend
        └───────────┬────────────┘
   1. guard.precheck  — пусто? слишком длинно? prompt-injection? приветствие?
   2. i18n.detect_lang — kk / ru
   3. LLM: переформулировка вопроса в поисковый запрос (перевод с каз., учёт истории)
   4. Retriever.search — BM25 + эмбеддинги → RRF → top-5 фрагментов  ← База знаний (kb/*.md)
   5. Порог релевантности: ничего не найдено → «нет подтверждённой информации» / «не по теме»
   6. LLM: ответ СТРОГО по фрагментам, со ссылками [1][2]; иначе NO_ANSWER / OFF_TOPIC
   7. Пост-обработка: пометка «Закреплено в Конституции РК 2026: Статья N» (из метаданных,
      детерминированно), список источников со ссылками
   8. analytics.log_query → SQLite (data/analytics.db)
                    ▼
            Ответ пользователю + 👍/👎
```

## Компоненты

| Компонент | Файл | Что делает |
|---|---|---|
| Конфигурация | `app/config.py` | читает `.env`; провайдер LLM меняется без правки кода |
| Загрузчик БЗ | `app/rag/loader.py` | markdown + YAML-шапка → фрагменты; законы режутся **по статьям**, чтобы ссылаться на конкретную статью |
| Поиск | `app/rag/retriever.py` | BM25 (своя реализация, стемминг по 5 буквам для каз./рус.), опционально эмбеддинги; объединение Reciprocal Rank Fusion |
| LLM | `app/llm.py` | OpenAI-совместимый клиент: Gemini / OpenAI / Llama (Groq, Ollama) |
| Промпты | `app/prompts.py` | правила: только по контексту, ссылки, нейтральный официальный тон, язык вопроса |
| Конвейер | `app/assistant.py` | шаги 1–8 выше, резервный режим без LLM |
| Фильтр | `app/guard.py` | быстрые проверки до вызова модели (экономия и безопасность) |
| Аналитика | `app/analytics.py` | статистика, вопросы без ответа, оценки |
| Викторина | `app/quiz.py`, `kb/quiz.json` | вопросы составлены вручную по Конституции — ответы гарантированно верные |

## Почему так

- **RAG, а не «голая» LLM** — модель не знает Конституцию 2026 (она новее обучающих данных многих моделей);
  все факты берутся из базы официальных текстов, поэтому ответ можно проверить по ссылке.
- **Два уровня защиты от выдумок**: порог релевантности поиска (до модели) и правило `NO_ANSWER` (в модели).
- **Пометка о Конституции — не на усмотрение модели**, а из метаданных документа, поэтому требование
  п. 4.1 Положения выполняется всегда.
- **BM25 работает без интернета и ключей**, эмбеддинги — улучшение, а не зависимость.
- **Резервный режим**: при сбое API бот показывает дословную выдержку из документа — демо не «падает».
- **OpenAI-совместимый протокол**: можно перейти на локальную Llama (Ollama) для работы в закрытом контуре госоргана.

## Данные и безопасность

- Персональные данные не хранятся: только SHA-256-хэш ID пользователя, текст вопроса, статус, время ответа.
- Секреты — в `.env` (в `.gitignore`), пример — `.env.example`.
- Rate-limit 20 запросов/мин на IP, лимиты длины текста (1500 символов), аудио (2 мин / 10 МБ).
- HTML из ответа модели экранируется перед показом (защита от XSS).
