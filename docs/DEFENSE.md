# План защиты (3–5 мин + 3 мин вопросы)

## Распределение ролей
- **Нурул** — руководитель/автор идеи: открывает, проблема и ценность (1 мин), закрывает.
- **Backend/AI** — демо и архитектура (2 мин), отвечает на технические вопросы.
- **Ергали / Ади** — база знаний и источники, веб-интерфейс, аналитика; держат второй экран с README/кодом.

Каждый должен уметь объяснить: что такое RAG, как работает `assistant.ask()`, откуда берутся источники,
как бот понимает казахский (п. 6.7, 10.4 Положения — за непонимание кода снимают баллы).

## Сценарий (≈4 мин)
1. **Проблема (30 с).** Новая Конституция вступила в силу 1 июля 2026; гражданину нужно быстро и
   достоверно понять, что в ней и в программных документах. Обычные чат-боты выдумывают.
2. **Решение (30 с).** «Адал Кеңесші» — навигатор, отвечает только по официальным текстам, со ссылкой
   и пометкой о Конституции. Казахский и русский, Telegram и веб.
3. **Демо (2 мин)** — заранее открыть Telegram и веб:
   - «Что означает принцип «Закон и Порядок»?» → ответ + 📜 «Закреплено в Конституции: преамбула» + ссылки.
   - Голосом на казахском: «Президент неше жылға сайланады?» → ответ по-казахски, статья 43.
   - «Сколько депутатов в Курултае и как их избирают?» → ст. 53.
   - Ловушка: «Какая зарплата у депутата?» → «нет подтверждённой информации» (п. 4.9).
   - Не по теме: «Как приготовить плов?» → вежливый отказ.
   - /quiz — одна викторина.
4. **Архитектура (40 с)** — показать схему из ARCHITECTURE.md: guard → переформулировка → RAG → LLM → источники.
5. **Безопасность и итог (20 с)** — ключи в .env, rate-limit, защита от инъекций, резервный режим; аналитика вопросов без ответа.

## Вероятные вопросы жюри
- *Почему бот не выдумывает?* — два барьера: порог релевантности поиска и правило NO_ANSWER; ответы со ссылками [n] на фрагменты.
- *Откуда база знаний?* — adilet.zan.kz (полные тексты, скрипт fetch_sources.py), akorda.kz, gov.kz; у каждого файла указан URL.
- *Как определяется, что принцип есть в Конституции?* — метаданные `in_constitution` у документа, пометка ставится кодом, не моделью.
- *Почему BM25, а не только эмбеддинги?* — работает офлайн, точно ловит номера статей и термины; эмбеддинги добавляют смысловой поиск; объединяем RRF.
- *Как с казахским?* — определение языка по буквам ә, ғ, қ, ң, ө, ұ, ү, һ, і; вопрос переводится в поисковый запрос; модель отвечает на языке вопроса; Whisper понимает казахский.
- *Что если API упадёт?* — резервный режим: дословная выдержка из документа.
- *Персональные данные?* — храним только хэш ID, без имён/телефонов.
- *Масштабирование?* — заменить SQLite на PostgreSQL, эмбеддинги в pgvector, LLM можно развернуть локально (Llama через Ollama) для госконтура.
