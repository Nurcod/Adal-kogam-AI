# Адал Кеңесші — AI-навигатор по внутренней политике Казахстана

Проект команды для конкурса AI-ботов **«Адал қоғам»** (МУИТ × Центр общественного развития УВП г. Алматы, 2026).

**Адал Кеңесші** — интеллектуальный справочник-навигатор: по вопросу на казахском или русском он
находит нужное место в **официальных документах** (Конституция РК 2026, законы, Послания Главы
государства, ключевые принципы — «Закон и Порядок», «Справедливый Казахстан», «Адал азамат»,
«Таза Қазақстан» и др.), понятно объясняет его и **даёт ссылку на первоисточник**.
Если концепция закреплена в Конституции 2026 года — бот обязательно это указывает (с номером статьи).
Если подтверждённого ответа нет — бот честно сообщает об этом, а не выдумывает.

## Проблема и решение

| Проблема | Решение |
|---|---|
| Новая Конституция и программные документы — большие тексты, гражданину сложно быстро найти нужное | Поиск по смыслу + краткое объяснение простым языком |
| Обычные чат-боты «галлюцинируют» и путают факты | RAG: модель отвечает **только** по найденным фрагментам официальных документов, с номерами ссылок [1], [2] |
| Информация нужна на двух языках | Полная поддержка казахского и русского (текст и голос) |
| Непонятно, на что опирается ответ | Каждый ответ — с источником (adilet.zan.kz, akorda.kz, gov.kz) и пометкой «Закреплено в Конституции РК 2026: Статья N» |

## Возможности

- 💬 Вопросы на естественном языке (казахский / русский), учёт контекста диалога
- 📚 RAG по базе официальных документов, ссылки на первоисточники
- 📜 Автоматическая пометка, если принцип закреплён в Конституции 2026 (с номером статьи)
- 🛡 Отказ от догадок (`NO_ANSWER`), фильтр тем (`OFF_TOPIC`), защита от prompt-injection, лимит запросов
- 🎙 Голосовые вопросы (Telegram voice и микрофон в веб-версии, Whisper — понимает казахский)
- 🧠 Викторина по Конституции (геймификация), темы-подсказки
- 👍/👎 оценки ответов и аналитика: популярные темы, вопросы без ответа (что добавить в базу)
- 🔁 Резервный режим: если AI-модель недоступна, бот показывает дословную выдержку из документа
- 2 платформы: **Telegram** и **Web**

## Быстрый старт

```bash
git clone https://github.com/Nurcod/Adal-kogam-AI.git && cd Adal-kogam-AI
python -m venv venv && source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                 # вписать LLM_API_KEY, TELEGRAM_BOT_TOKEN и др.

python scripts/fetch_sources.py      # (рекомендуется) скачать полные тексты с adilet.zan.kz
python -m pytest -q                  # тесты (работают без ключей)

uvicorn web_app:app --port 8000      # веб-версия → http://localhost:8000
python telegram_bot.py               # Telegram-бот
```

Или через Docker: `docker compose up --build`.

Ключи: Gemini — бесплатно на https://aistudio.google.com/apikey, Groq (голос) — https://console.groq.com/keys,
Telegram — у @BotFather. **Ключи хранятся только в `.env`, который не попадает в репозиторий.**

## Технологии

| Слой | Технология |
|---|---|
| Язык | Python 3.11+ |

## Структура

```
app/
  config.py          настройки из .env
  assistant.py       главный конвейер ответа (RAG + LLM + источники)
  rag/loader.py      загрузка базы знаний, нарезка по статьям

  llm.py             клиенты LLM и распознавания речи
  prompts.py         системный промпт и правила ответа

scripts/             загрузка официальных текстов
web/index.html       веб-интерфейс
telegram_bot.py      Telegram-бот

```

## Как пополнять базу знаний

Добавьте файл `kb/<тема>.md`:

```markdown
---
title: Название
title_kk: Атауы
aliases: [синоним, ещё синоним]
sources:
  - Название источника | https://официальный-url
in_constitution: "Преамбула Конституции РК 2026"   # или пусто
---
Текст — пересказ или выдержка из официального документа.
```

Перезапустите бота — документ проиндексируется автоматически. Полные НПА добавляются строкой в
`scripts/sources.yaml` и командой `python scripts/fetch_sources.py`.

## Источники информации

- Конституция РК, принятая на референдуме 15.03.2026 — https://adilet.zan.kz/rus/docs/K2600000000
- Эталонный контрольный банк НПА РК — https://adilet.zan.kz
- Официальный сайт Президента РК (Послания, выступления) — https://www.akorda.kz
- Портал государственных органов — https://www.gov.kz
- Полный список — в шапках файлов `kb/` и в `kb/SOURCES.md`.

## API

| Метод | Описание |
|---|---|
| `POST /api/chat` `{question, session_id}` | ответ бота: `status`, `html`, `sources`, `constitution` |
| `POST /api/voice` (multipart `file`) | распознавание голоса → текст |
| `POST /api/rate` `{query_id, value}` | оценка ответа |
| `GET /api/quiz`, `GET /api/quiz/{id}/{answer}` | викторина |
| `GET /api/stats?token=` | аналитика (для администратора) |
| `GET /health` | состояние сервиса |

## Безопасность

- секреты только в `.env` (в `.gitignore`); в аналитике хранится хэш ID пользователя, без имён и телефонов;
- лимит 20 запросов/мин с одного IP, ограничение длины вопроса и размера аудио;
- защита от prompt-injection до обращения к модели + правило в системном промпте;
- ответы только по официальным источникам, без генерации предположений (п. 4.9 Положения).
